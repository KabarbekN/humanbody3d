# 3D Anatomy Explorer v5

Статический 3D-анатомический атлас для GitHub Pages. Серверная часть и сборка не требуются.

## Обновление с v4

Замените в корне репозитория:

- `index.html`
- `styles.css`
- `app.js`

Добавьте новые файлы:

- `anatomy-data.js`
- `sw.js`
- `manifest.webmanifest`
- `icon.svg`
- `maskable-icon.svg`

Файлы `.nojekyll`, `ATTRIBUTION.md` и `LICENSE` можно оставить прежними.

## Возможности v5

1. Иерархическое дерево анатомических систем и областей.
2. Изоляция выбранной структуры, связанных структур или всей системы.
3. Подписи анатомических структур непосредственно над 3D-моделью.
4. Поиск на русском и английском, по латинскому названию, FMA ID, системе и стороне тела.
5. Учебные маршруты с автоматической камерой и переключением слоёв.
6. Интерактивный тест «Найдите структуру».
7. Расширенная карточка структуры: описание, положение, функции и связи.
8. Три независимых плоскости среза: сагиттальная, фронтальная и аксиальная.
9. Измерение расстояния между двумя точками цифровой модели.
10. Пользовательские аннотации с сохранением в `localStorage`.
11. Экспорт текущей 3D-сцены в PNG.
12. Ссылки, восстанавливающие камеру, активные слои, срезы и выбранный объект.
13. PWA и Service Worker для кэширования интерфейса и загруженных STL-моделей.
14. Выгрузка скрытых слоёв из оперативной и GPU-памяти.
15. Диспетчер загрузки: прогресс по системам, отмена и повтор ошибок.

## Запуск локально

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## GitHub Pages

В `Settings → Pages` выберите:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

Все пути в проекте относительные, поэтому он работает по адресу вида:

```text
https://username.github.io/repository-name/
```

## Диагностические параметры

```text
?quality=low
?quality=high
?bvh=off
?lod=off
?assets=local
```

Параметр `assets=local` предполагает наличие STL-файлов в папке `models/`.
