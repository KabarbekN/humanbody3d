# 3D Anatomy Atlas — GitHub Pages

Компактный статический Three.js-визуализатор. HTML, CSS и JavaScript размещаются на GitHub Pages, а анатомические STL-меши загружаются во время работы из открытого зеркала BodyParts3D.

## Публикация

1. Создайте новый публичный репозиторий.
2. Загрузите **содержимое этой папки в корень репозитория**.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/(root)` и нажмите `Save`.
6. Подождите несколько минут и откройте выданный адрес.

Все локальные пути относительные, поэтому проект работает и по адресу вида:

`https://username.github.io/repository-name/`

Файл `.nojekyll` отключает обработку Jekyll. Сервер и сборка не нужны.

## Что находится в репозитории

- собственный интерфейс и логика визуализатора;
- перечень используемых FMA-структур;
- ссылки для загрузки моделей;
- сведения об источнике и лицензии.

Полная копия исходного BodyParts3D в репозиторий **не включена**. Поэтому этот проект не является копией исходного репозитория: он представляет собой отдельный веб-визуализатор, использующий его открытые данные.

## Лицензирование данных

Геометрия BodyParts3D распространяется по CC BY-SA 2.1 Japan. Не удаляйте:

- постоянную подпись `BodyParts3D · CC BY-SA 2.1 JP` в интерфейсе;
- `ATTRIBUTION.md`;
- сведения об источнике в диалоге лицензии.

При добавлении STL-файлов непосредственно в этот репозиторий вы начнёте распространять копию или подмножество данных. Для таких файлов необходимо сохранить атрибуцию и условия ShareAlike.

Код визуализатора и анатомические данные являются разными частями проекта и могут сопровождаться разными лицензиями.

## Ограничения

- При первом открытии необходим интернет.
- Доступность моделей зависит от внешнего зеркала BodyParts3D.
- Проект предназначен для обучения и визуализации, а не медицинской диагностики.
